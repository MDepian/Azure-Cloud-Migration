# ☁️ Azure Cloud Migration Portfolio

Welcome to my Azure Cloud Migration repository! This repository serves as a centralized showcase of end-to-end cloud migration projects, featuring real-world client scenarios and hands-on lab implementations.

---

## 🎯 Repository Purpose

The goal of this repository is to demonstrate practical methodologies for migrating workloads to Microsoft Azure, adhering to the **Cloud Adoption Framework (CAF)**. 

Inside, you will find projects covering:
* **Business Case Generation & Assessment:** Financial TCO analysis, ROI calculations, performance-based sizing, and dependency mapping.
* **Workload Migration Strategies (7 Rs):**
  * **IaaS (Rehost / Lift-and-Shift):** Migrating virtual machines and infrastructure components.
  * **PaaS (Replatform / Refactor):** Modernizing databases (Azure SQL) and web apps (Azure App Service).
* **Migration Wave Planning:** Grouping workloads, defining readiness criteria, and executing migration schedules.
